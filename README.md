# Agent Skills

Some useful skill definitions for AI agents. Made these for Cursor, but should work in most AI tools.


| Skill                                      | What it does                                                                                       |
| ------------------------------------------ | -------------------------------------------------------------------------------------------------- |
| [senior-engineering](./senior-engineering) | Engineering principles for large-scale software development. Writing code was never the hard part. |
| [technical-writing](./technical-writing)   | Technical docs which are well structured, accurate and less overwhelming to read.                  |




## Installation



### Easy-mode

Tell your agent to `Install the skills from git repo https://github.com/robinerd/robinerd-agent-skills`

### Cursor

Clone this repo. Copy each skill folder into one of these:

- **All projects:** `~/.cursor/skills/<skill-name>/`
- **One repo:** `.cursor/skills/<skill-name>/`

Or in Cursor: **Customize → Skills**, then grab this repo from GitHub (`https://github.com/robinerd/robinerd-agent-skills`).
